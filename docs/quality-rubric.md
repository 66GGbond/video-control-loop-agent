# Quality Rubric

Scores are from 1 (unusable) to 5 (strongly meets intent).

| Dimension | What is measured | Release relevance |
|---|---|---|
| Instruction following | Character, action, setting and emotion match the shot brief | Core gate |
| Character consistency | Identity, wardrobe and defining visual attributes persist | Core gate |
| Camera control | Shot scale, composition and requested motion follow the plan | Supporting |
| Visual quality | No distracting deformation, flicker or physical defect | Blocking defect may fail release |
| Narrative continuity | Props, positions, actions and emotional state transfer across shots | Core gate |
| Audio-visual alignment | Speech/subtitle semantics agree with the visual event | Supporting |

## Release policy

- Overall average is at least 4.0.
- Each core gate is at least 3.0.
- No `blocking` Bad Case remains.

The rubric and policy are deterministic configuration. The evaluator may supply evidence and scores, but it cannot redefine the release bar.
