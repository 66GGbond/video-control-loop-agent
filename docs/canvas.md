# 本地画布与全局创作 Agent

左侧导航提供 `VCL Agent` 和 `画布`。两页共用现有的创作 Agent、输入草稿、参考附件、修复预算与模型确认；右下角胶囊在浮窗关闭时显示，展开后隐藏。Agent 在所有屏幕上以接近页面全高的透明浮窗展开，直接覆盖右上角工具栏，不挤压工作区、不移动节点或工具栏；关闭后露出原有工具栏。对话区独立滚动，输入区固定在底部。已提交的需求、修改、背景确认及规划回复保存在当前本地项目中，切换工作区、关闭浮窗、刷新或重启后仍可查看；重置项目会清空该项目的聊天，并关闭浮窗、恢复胶囊入口。浮窗标题栏只保留名称和关闭按钮。旧项目只恢复仍存留的原始需求、累计修改和待处理指令，不补造已丢失的历史回复。

## 画布操作

- 侧边工具栏或空白处双击/右键：添加文字、图片、视频参考、音频、视频任务或便签。
- 拖动节点标题栏移动节点。Shift 点击或拖出选区可多选；单个节点的操作图标收进标题栏；多选时显示批量操作条。复制、删除只保留一组，均可撤销；交给 Agent 仅显示图标并提供悬停提示。
- 点击节点右侧端口，再点击目标节点左侧端口连接；重复、自连接和循环会被拒绝。选中连线后可删除。
- 滚轮/触控板平移，Ctrl/Cmd + 滚轮缩放；空格临时平移。底部提供选择、平移、缩放、适应与连线显示。
- 快捷键：V 选择、H 平移、F 适应、Cmd/Ctrl+A 全选、Cmd/Ctrl+D 复制、Delete 删除、Cmd/Ctrl+Z 撤销、Cmd/Ctrl+Shift+Z 重做。输入框保留原生文字编辑行为。
- 项目素材面板可把当前项目的 Brief、参考图片/音频/视频和已生成版本放入画布。生成版本可预览，来源项目已重置时显示不可用。
- 顶部支持画布命名、JSON 导入/导出。左下角语言按钮切换中英文；用户文字、素材名和已有模型输出保持原文。

## 如何连接现有 Agent

视频任务的「交给 Agent」收集沿输入连线可达的文字与参考素材，按依赖顺序整理，并保留 `@文件名` 关联。便签不进入创作需求，未连接的节点不会被隐式收集。多选后「交给 Agent」收集选中节点及其上游。

交接结果加入同一个可编辑草稿，用户发送后才进入原有规划流程。画布不直接提交付费生成；模型确认卡在画布视图移入 Agent 面板，仍执行原有兼容性筛选、用户确认、预算和质量门。画布是当前项目的素材与创作组织空间，不是并行执行多个独立项目的工作流引擎。

已有计划的修改沿用其参考素材。要为新任务替换参考素材，应先重置项目；系统会明确提示，避免把新的素材悄悄丢弃。生成版本的本地地址不能直接供远端模型参考，连接这种节点交接时会提示添加公网视频链接。

## 当前能力与保存

图片可作为用户参考素材导入，也可通过「图片生成」节点生成；音频复用现有 MP3/WAV 处理，视频参考通过公网 HTTPS URL 加声明时长接入。参考视频不会因打开画布自动下载，点击预览才加载。坐标式图片编辑、图层拆分和时间线剪辑尚未接入。

## 画布生图

图片生成节点可接入文字和最多 10 张图片，保留用户需求与有序 `@` 关联。运行时选型技能 `image_model_selection.md` 配合能力卡片，由 Doubao Seed 2.1 Pro 推荐 `doubao-seedream-5-0-pro-260628` 或 `doubao-seedream-5-0-flash-260915`，用户可改选，点击「确认生成」才提交生图。Pro/Flash 的差异依据官方定位；本项目没有可比效果、延迟和实时价格基准，备用规则推荐会单独标注。

当前适配器统一生成单张 2K、含水印的 PNG。使用官方 `b64_json` 返回方式将原图持久保存在本地，避免 24 小时 URL 过期。结果自动成为图片节点，画布中使用压缩预览，提供原图下载；项目素材库可找回生成结果。已生成图片是依赖边界，下游只引用成图，不会重新执行上游生图任务，也不会把旧生图提示词混入视频需求。

输入或配置变化会使旧推荐失效。一次确认绑定一个模型和一个请求，重复点击、轮询或刷新不重复提交；失败不自动换模型，断网或进程中断将标为状态未确认，需先查看方舟控制台。服务端专用密钥为 `SEEDREAM_PRO_API_KEY` 和 `SEEDREAM_FLASH_API_KEY`，不进入网页、导出文件或 Git。VCL Agent 内的独立生图嵌入方式暂未改动。

能力与接口来源：[Seedream 5.0 Pro / Flash](https://docs.volcengine.com/docs/ark/seedream-5-0-pro?lang=zh)、[图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)。

每次编辑、移动和视图操作后，画布自动保存草稿；标题旁图标只表示保存状态，无需点击。暂时断网后自动重试保存。画布按本地会话保存到现有 SQLite 中的独立表，重启服务和刷新后可恢复，也不受项目重置影响。保存采用修订号检查；其他标签页抢先保存时拒绝覆盖，保留本页内容并提示先导出再刷新。未保存时关闭/刷新会触发浏览器的离开提示。

当前限制为 100 个节点、250 条连线、32 MB 画布文件、20%–200% 缩放。媒体在服务端按现有参考校验再次规范化，导入会拒绝循环连线、非法类型、无效 URL 和不合理坐标。导出文件包含画布引用的用户素材，不包含服务端 API Key。
